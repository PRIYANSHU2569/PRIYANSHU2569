### 🏢 QuickEMS — Employee Management System

🔗 **Live Demo:**  
https://fullstack-ems-khaki.vercel.app/dashboard

🔗 **Backend API:**  
https://fullstack-ems-server-green.vercel.app/

🔗 **Repository:**  
[Add your QuickEMS GitHub repository link here](https://github.com/PRIYANSHU2569/FULLSTACK-EMS)

> React • Node.js • Express.js • MongoDB • JWT • Nodemailer • Brevo SMTP • Inngest

QuickEMS is a full-stack Employee Management System designed to simplify employee administration, attendance tracking, leave management, payroll records, and automated email notifications.

**Key Features:**

- 👨‍💼 Role-based Admin and Employee authentication
- 🔐 Secure JWT authentication and authorization
- 👥 Complete employee management system
- 🕒 Employee check-in and check-out attendance tracking
- 📝 Leave application, approval, and rejection workflow
- 💰 Employee payslip and payroll management
- 📊 Role-based Admin and Employee dashboards
- 📧 Transactional email notifications using Brevo SMTP
- ⚙️ Background workflows using Inngest
- ⏰ Automated attendance and leave reminder emails
- 🧪 Admin-only SMTP email testing endpoint
- 🗄️ MongoDB Atlas database integration
- 🚀 Frontend and backend deployed on Vercel
